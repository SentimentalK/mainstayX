## 1. 视觉参考（必读）

`design/explorations/` 是我确认过的静态风格稿，打开 `synthwave.html` 就能看到。**只用「落日合成波 synthwave」这一个主题**，其他主题和 1-bit 抖动开关都不要。

- `engine.js`：320×180 低分辨率 Canvas2D 绘制、像素精灵矩阵（Clawd、Orca、各家 agent）、条纹落日、透视网格、门、穿梭速度线、bloom 叠加的做法
- `themes.js` 里 `id: 'synthwave'` 的调色板：照这个配色走
- 这些素材和构图可以直接沿用、重构、扩展。精灵可以重画得更精致，加更多帧，但要保持同样的像素风和配色
- 角色是对各家 CLI / AI 的**致敬**：可以用代表色和特征元素，**不要用任何官方 logo 原图**

## 2. 体验流程

用状态机串起来：`DOOR → KNOCK → OPEN → GREET → WARP → WORLD`

1. **DOOR**：合成波场景，门立在地平线上，落日在门后面。闪烁的提示 `▶ CLICK TO KNOCK`
2. **KNOCK**：每点一下门，门震动几帧，弹出一个像素风 `KNOCK!`（位置和角度随机，弹出后淡出），同时播敲门音效。点到第 3 下触发开门
3. **OPEN**：门左右滑开，里面透出强光，地面出现光锥
4. **GREET**：Clawd（橙色小螃蟹）从门里走出来，挥手，冒出 `HI!` 气泡，然后转身走回门里。**从这一步起全部自动播放，不再需要点击**
5. **WARP**：镜头冲进门里，接一段约 2–3 秒的穿梭：速度线、光效、隧道框、轻微屏幕震动，最后白闪切进新世界
6. **WORLD**：agent 世界一直循环运行（见第 4 节，这是重点）

回访和跳过：
- 第一次访问播完整流程。用 localStorage 记住已经看过，**再次访问直接进 WORLD**，角落放一个 `↺ replay intro` 按钮
- 开场过程中右下角一直有 `skip ▸`
- `prefers-reduced-motion` 时直接进 WORLD，并降低动画强度
- 调试参数：`?scene=door|warp|world` 直接跳到某一幕，`?seed=123` 让随机行为可复现

## 3. 8-bit 音乐和音效（WebAudio 实时合成，不要音频文件）

- 第一下敲门就是用户手势，在这一刻解锁 AudioContext。这正好是设计上的巧合，利用起来
- 音效：
  - 敲门：低频方波短促一下，叠一点噪声
  - 开门：上行琶音 + 嘶嘶声
  - Clawd 打招呼：两声可爱的 blip
  - 穿梭：音高上扫 + 白噪声渐强，切入世界时一个重拍
- 进入 WORLD 后循环播放一首 **synthwave 风的 chiptune BGM**：
  - 约 100–118 BPM
  - 方波主旋律，三角波 / 锯齿贝斯琶音，噪声鼓（kick / snare / hat）
  - 16–32 小节循环，要有段落变化，不能 4 小节死循环
  - 用简单的音序器数据结构写，方便以后改曲
- 世界里的事件也配轻量音效：消息送达的 blip、找到东西的 jingle 等。音量要克制，别吵
- 右下角静音按钮，状态存 localStorage。默认音量适中

## 4. Agent 世界：让它真的"忙起来"（重点，最花心思的部分）

**场景本身要动：**
- 网格地面持续往前滚动（经典 synthwave 效果）
- 落日条纹缓慢移动，星星闪烁，偶尔划过流星
- 远山轻微视差

**Orca（中心调度者）：**
- 悬浮上下浮动，尾巴摆动，脚下有脉冲光环
- 时不时从头顶喷水，一个小水柱粒子
- 定期往某个 agent "派活"：一个发光的任务包沿连线飞过去

**Agent 角色：** Claude（Clawd）、Gemini、Codex、Qwen、Kimi，加上会被临时召唤出来的小号 Clawd 子 agent。

- 每个 agent 有自己的行为状态机，至少包括：idle（呼吸、眨眼）、走动 / 跑动（2–4 帧走路循环）、收到任务、干活（敲键盘的火花、进度小条）、交付结果（结果包飞回 Orca）
- 连线和消息流是**动态的**：谁在和谁通信，线就亮起来，包在线上跑，送达时闪一下

**随机小剧场（核心乐趣）：** 用一个带权重和冷却的随机事件调度器，同一时间只上演 1–2 个，不要乱成一锅粥。至少实现 8 个：
1. **找不到东西**：agent 左右张望，头上冒 `?`，原地转圈，最后在身后找到，冒出 `!`，配一声 jingle
2. **东西丢了**：agent 跑的时候掉了一个任务包，跑出去一段才发现，急刹车，`!`，掉头跑回去捡
3. **撞车**：两个 agent 跑着撞在一起，都弹开，冒出星星，然后互相 `sorry` 气泡
4. **召唤子 agent**：Claude 拍一下，"噗"地分裂出 2–3 个小 Clawd，四散跑去不同方向办事，办完跑回来合体
5. **开会**：Orca 发出召集信号，几个 agent 跑到它身边围一圈，头上冒出对话气泡（像素图标或很短的词），然后散会
6. **接力传递**：一个包从 A 传给 B 再传给 C，像传球一样
7. **庆祝**：任务完成，agent 原地跳，头顶冒像素彩带
8. **打瞌睡**：某个 agent 闲久了冒 `zzz`，被 Orca 的 ping 吓醒，一个激灵
9. 你自己再想几个更有趣的，越有"小人在办公室里瞎忙"的喜感越好

- 气泡内容：短英文、符号或像素图标，例如 `on it!` `>_ done` `?` `!` `brb` `lgtm` `where's my ctx??`
- 鼠标悬停 agent 时显示名字标签，被悬停的 agent 停下来看向鼠标
- **以后的扩展只留接口，不做界面**：点击 agent 会弹出对应项目（语音输入、K3s home lab、CEO、008）和 GitHub 链接。现在只要建好 `src/data/agents.ts` 这类配置（名字、颜色、项目、链接占位），点击时 `console.info` 一下即可

## 5. 技术要求

- **Vite + TypeScript，渲染用原生 Canvas2D**，不引入游戏框架。参考稿已经是 Canvas2D，320×180 的分辨率下性能完全不是问题
- 在 320×180 的离屏 canvas 上渲染，按整数倍、最近邻放大到视口，居中留黑边；`image-rendering: pixelated`
- bloom 沿用参考稿的做法：模糊叠加层 + screen 混合，必要时降频更新
- 可以加很淡的扫描线
- 稳定 60fps：静态层预渲染缓存，主循环里避免频繁分配对象，标签页隐藏时暂停循环和音乐
- 建议的目录结构（可以调整）：`src/engine/`（主循环、输入、像素绘制工具、缓动）、`src/scenes/`（door / greet / warp / world）、`src/sprites/`、`src/audio/`（合成器、音序器、曲子、音效）、`src/world/`（agent 状态机、事件调度器）、`src/data/`
- 可访问性和 SEO：canvas 之外放一层视觉隐藏的 DOM，写上站点名、一句介绍和占位链接；静音和跳过按钮要能用键盘操作
- 桌面优先。手机上不用专门适配，但不能报错或崩掉，能缩放显示即可

## 6. 部署准备（不要碰集群）

- 多阶段 `Dockerfile`：node 构建，然后 `nginx:alpine` 托管静态文件
- `nginx.conf`：gzip，带 hash 的资源长缓存，`index.html` 不缓存
- `deploy/k8s/` 下放示例 Deployment、Service、Ingress，域名和镜像地址用占位符，写清楚哪些需要我改
- README 写本地开发、构建、打镜像的命令

## 7. 工作方式：用子 agent 并行，并且管好 token

你是 lead，负责规划、定接口、集成和验收。

1. **先规划**：读完参考稿后，写一份简短的 `docs/PLAN.md`，内容包括模块划分、模块之间的 TypeScript 接口（场景接口、精灵和动画帧格式、音频 API、世界事件接口）、每个模块负责哪些文件。然后先由你搭好项目骨架和共享类型
2. **再并行**：骨架和接口定下来后，用子 agent 同时开发互不重叠的模块，建议 3–4 个：
   - 音频（合成器、音序器、BGM、音效）
   - 精灵和动画帧（重画 / 扩展像素矩阵、走路循环、表情、粒子）
   - 世界行为（agent 状态机、随机小剧场调度器、消息流）
   - 开场幕（门、敲门、开门、打招呼、穿梭）

   每个子 agent 只改分配给它的文件，共享类型由你维护。

**token 管理：**
- 给子 agent 的任务说明要写清楚：目标、要读哪些文件、要实现哪些接口、验收标准、不要碰哪些文件。不要让它自己从头探索整个仓库
- 让子 agent 返回**简短总结**（做了什么、接口有没有变化、已知问题），不要把整个文件内容贴回来
- 你自己不要反复全文阅读大文件，按需读相关片段
- 子 agent 不超过 4 个同时跑；一件事几次工具调用能搞定的，就自己做，不要开子 agent
- 截图验证要有针对性，别每改一行就截一次

## 8. 验收（做完前必须自己检查）

- `npm run build` 和 TypeScript 类型检查通过，浏览器控制台无报错
- 用 Playwright（或无头 Chrome）分别截 `?scene=door`、敲门中、`?scene=warp`、`?scene=world` 几帧，自己看图确认画面正确、没有错位、文字清晰
- 在 WORLD 里用固定 seed 跑 60 秒以上，确认随机小剧场确实轮流出现、不卡死、不越界、内存不涨
- 确认音频只在用户点击后才启动，静音按钮有效
